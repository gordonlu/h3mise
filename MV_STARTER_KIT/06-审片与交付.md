# 从可播放素材到完整 MV

## 把不同结论分开

| 观察 | 能说明什么 |
| --- | --- |
| 返回远端任务号 | 请求被受理 |
| LOCAL_READY | 产物回收到本地 |
| 完整解码、尺寸与帧数正常 | 文件技术上可用 |
| 静帧正常 | 该时刻正常 |
| 连续看完整段 | 才能检查运动、场景稳定和人物变化 |
| 原曲对照口型 | 可见发音、停顿与尾音是否跟随 |
| 用户通过 | 对应版本与采用范围被接受 |

成功返回、音频相关性、ASR 或静帧均不能替代完整音画审看。尤其检查句尾、镜头最后一秒、背景人群、物件和脸部肤色。已通过的素材不因旧计划反复重生。

## 剪辑与声音

保留无字母版，最终用完整原曲原速连续覆盖。生成音轨单独检查、单独记录，后期原曲对齐另行验收。保存每条 Take 实际采用的源帧、入点、出点和速度，避免只记“用了这条”。

使用 H3Mise 时间线或自己的剪辑软件完成组接。外部剪辑时，另存剪辑记录并将成片作为媒体回存 H3Mise；导入媒体不等于自动生成应用内的时间线导出记录。不要因待完成计数仍未清零而重复生成。

转场为叙事服务。相近室内人物镜头切换生硬时可用短淡变；不必每个切点加特效。人物动作应有真实进展，避免整片慢动作和相同背景反复对脸。

## 歌词、片头与片尾

以原歌词为文字来源，ASR 仅辅助定位。逐句检查漏词、重复和长句断行，按实际唱法对齐。字体选择兼顾设计与手机阅读，保留字体许可；在约 375 像素宽画面上检查实际字号、描边、对比与安全边距。

先锁定片头、创作信息与片尾出现的时间位置，再排版。用户需要 demo 时先给 demo；已经明确直接全曲输出时不再追加预览审批。尽量从无字母版一次完成最终叠字，减少反复压制。

## 费用与投稿

记录实际扣费、币种、换算依据、手动任务和失败是否扣费。未知费用不填 0；已知小计不写成全部成本。片尾分别说明音乐、视频、人工和 Agent 的实际分工。

封面优先从真实成片取帧，按横版、4:3、3:4分别排版，保留面部和标题手机可读性。标题与简介准确描述作品与创作方式，按投稿平台当前要求填写创作声明。

## 收尾

交付最终视频、无字母版、字幕源、字体许可、封面、投稿文案、采用记录和当前交接。核对已有任务及费用，不再有未解释的在途状态。

整理外部项目时分开输入素材、审片版本、交付和证据；不要直接移动 H3Mise 内部工程媒体。将可复用方法留在通用文档，把具体歌曲、人物、任务号、路径与费用留在该项目记录。
