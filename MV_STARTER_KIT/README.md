# H3Mise MV 起步包

从一首歌开始，用 H3Mise 管理故事、人物、镜头、生成任务和审片决定，最后完成一支 MV。

本目录全部是 Markdown 文档，可以独立复制给其他人。无需原作者的项目、素材或脚本；准备自己的歌曲、歌词、人物图和 RunningHub 账号即可。它是操作指南与可复制模板，不是自动导入工程或一键生成程序。

[English version](en/README.md)

## 从这里开始

1. 阅读 [快速开始](01-快速开始.md)，先完成一个叙事镜头和一个演唱镜头的小样。
2. 按 [RunningHub 工作流](02-RunningHub工作流.md) 添加叙事 App 与原音频对口型 App。
3. 用 [演唱提示词](03-演唱提示词.md) 保持原唱时序；用 [叙事提示词](04-叙事提示词.md) 描述具体行动与空间。
4. 复制 [项目制作表](05-项目制作表.md)，填写自己的歌曲、故事、镜头、预算和审片记录。
5. 按 [审片与交付](06-审片与交付.md) 完成整片。
6. 如需 AI Agent 协助，把 [给 AI 助手的任务](07-给AI助手的任务.md) 填好后交给助手。

建议歌曲控制在 3 分钟内，优先约 2 分 30 秒；先验证真实样片，再批量制作。优先在生成阶段直接输出目标 1080p，并核对产物实际尺寸；这里记录的 App 接入成功不代表已经验证原生 1080p。

本文不包含 API Key、用户素材、本机目录、工程 ID 或历史任务。App ID 是可供接入的服务入口，是否能访问、收费和节点结构以接收者账号及 App 当前页面为准。

需要安装程序时，请随 H3Mise 一起使用；本目录可独立阅读，启动要求也写在快速开始中。
