# Narrative Shots: Move the Story with Action

Use the original reference images for characters and environments, binding identity, wardrobe, and environment roles separately. An ordinary image reference is not a fixed first frame; use first-frame mode only when the workflow really has a first-frame slot and this shot needs one.

## Write five things for every shot

1. **New information**: what the character completes, discovers, or chooses.
2. **Spatial relationships**: character position, facing, gaze, entrances and exits, and key object positions.
3. **Action process**: a clear start, middle, and end state, at normal real-world speed.
4. **Camera behavior**: one main movement with a start, end, and motivation; foreground and background create spatial change.
5. **Continuity conditions**: wardrobe, held items, light direction, movement direction, and the connection to the next shot.

## Copyable structure

Replace the brackets with your own content; this is a prompt-writing structure, not an H3Mise import format. Use narrative shots for the actual business; do not add words like "singing" or "lip sync" to shots without singing.

```text
Subject: the adult character in <Picture 1>, wearing [precise clothing].
Setting: the location in <Picture 2>, [time, light direction, spatial landmarks].
Action: [initial pose and location]. At normal real-time speed, the character
[one clear action with visible stages], ending [final pose, position and gaze].
Camera: [shot scale and angle], [one motivated camera behavior with start/end].
Spatial continuity: [screen direction, subject/object positions, view direction].
Background: [exact visible people count and their simple consistent actions,
or a quiet empty location if appropriate to the story].
Look: [natural skin tones, coherent light and materials, desired visual style].
```

For example, "closes both palms around a leaf, walks to the stream, opens her hands and lets the leaf drift away with the current" is more filmable than "she is sad." A detail can be its own shot, but it must change the audience's understanding of the story.

## Avoid visual fatigue and continuity errors

Wide shots establish space, medium shots express action, details carry choices, and singing lands on emotional beats. Short cuts need different new information; swapping a few clips repeatedly is not rhythm design. Use slow motion for a few meaningful moments, not as the default speed.

Plan a route that keeps moving forward and avoids returning to old locations without a reason. If several segments in the same space repeatedly change glass, buildings, or character facing, consider covering the character and key event completely in one shot with both in frame.

Background people also need definite actions; if the story allows, choose an empty location. State the correct hands, objects, and wardrobe state. Keep compositions and Takes the user has accepted; write revisions with the specific problem and the parts that must be preserved.
