# H3 Sequence Directing

Use this reference after StoryBeats are strong and H3 adaptation decisions are known.

This layer decides how multiple shots work together. It does not perform detailed direction inside one shot.

## Goal

Build the minimum shot sequence that makes the story:

- clear;
- progressive;
- emotionally readable;
- visually varied for a reason;
- compatible with MiniMax H3 production.

## 1. Every Cut Needs A Motive

Useful cut motives include:

- new information;
- changed action owner;
- reaction that changes meaning;
- reveal;
- spatial clarification;
- action handoff;
- sound handoff;
- time compression;
- a deliberate contrast;
- a new dramatic function.

Do not cut only because "it is time for another angle."

If the event reads better as one continuous H3 shot, keep it continuous.

## 2. Shot Function Before Shot Decoration

Assign each shot a primary function such as:

- reveal;
- discovery;
- decision;
- approach;
- confrontation;
- pursuit;
- escape;
- activation;
- transformation;
- impact;
- payoff;
- aftermath;
- scale reveal;
- transition when genuinely necessary.

A shot may have secondary effects, but it should have one dominant reason to exist.

## 3. Information Progression

For each shot ask:

> What does the audience know or feel after this shot that they did not know or feel before?

Useful progression may come from:

- revealing a subject;
- withholding a cause while showing an effect;
- showing danger before the character sees it;
- delaying a reaction;
- changing spatial knowledge;
- changing which character has control.

Avoid explaining everything early.

## 4. Rhythm Comes From Change, Not Shot Count

A sequence can accelerate by:

- shortening holds;
- increasing action density;
- reducing recovery time;
- increasing uncertainty;
- alternating action and reaction;
- compressing travel or procedure.

A sequence can slow by:

- holding on consequence;
- delaying response;
- using silence;
- letting a changed state register.

Do not add extra shots merely to manufacture pace.

## 5. Visual Variation Must Have A Job

Do not mechanically rotate:

```text
wide -> medium -> close-up -> wide
```

Use a change in scale, angle, or movement only when it supports:

- information;
- power;
- intimacy;
- isolation;
- speed;
- threat;
- reveal;
- aftermath.

Detailed lens and camera-path decisions belong to the downstream single-shot director.

## 6. Preserve Screen Direction And Spatial Logic

Track only what the sequence needs:

- left-to-right / right-to-left movement;
- facing;
- entrances / exits;
- relative subject positions;
- important environment anchors.

An intentional direction reversal is allowed, but it should be recognized as a decision rather than an accident.

## 7. Transition By State When Useful

Do not show every physical connector.

A clean sequence may use:

```text
Shot A exit state
CUT
Shot B entry state
```

when the omitted process has no dramatic value.

This is especially useful for:

- prop pickup already understood;
- routine travel;
- dressing / setup;
- repetitive mechanical procedure;
- repositioning before the next important event.

## 8. Sequence Escalation

Across a short episode, look for meaningful progression in at least one dimension:

- stakes;
- cost;
- information;
- speed;
- proximity;
- relationship pressure;
- danger;
- commitment;
- visual scale.

Do not require every sequence to escalate in all dimensions.

## 9. Ending A Sequence

The final shot should leave:

- payoff;
- consequence;
- unresolved pressure;
- decision;
- changed relationship;
- changed environment;
- aftertaste.

Do not end only because the requested duration is exhausted.

## Shot Sequence Contract

For each proposed shot provide:

```text
Shot ID
Story Beat
Shot Function
Dramatic Purpose
Entry State
Primary Visible Event
Exit State
Approx Duration
Screen Direction / Continuity Need
Reference Need
H3 Risk
Adaptation Note
```

Stop before detailed camera choreography, performance mechanics, or final prompt syntax.
